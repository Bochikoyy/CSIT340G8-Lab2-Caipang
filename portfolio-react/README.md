# Chrisnel Graine Caipang's Portfolio

A React and Tailwind CSS portfolio for CSIT340, rebuilt from the supplied `portfolio.html` reference using the 15 required components.

## Run locally

```bash
npm install
npm run dev
```

The app lives in this `portfolio-react` folder. Run these commands here. Use `npm run build` for a production build and `npm run lint` to check the source.
